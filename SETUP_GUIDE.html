🚀 Portfolio Setup Guide

📋 Panduan lengkap untuk setup portfolio Andika Bramastra

📁 Struktur Folder yang Dibutuhkan

portfolio-andika-bramastra/
│
├── index.html                  ← File HTML utama
├── styles.css                  ← File CSS
├── script.js                   ← File JavaScript
│
├── files/                      ← Folder untuk file download
│   └── CV_Andika_Bramastra.pdf ← File CV Anda (PDF)
│
└── images/                     ← Folder untuk gambar
    ├── project iot.jpeg        ← Project IoT
    ├── recell.jpeg             ← Recell Business
    ├── affiliate.jpeg          ← TikTok Affiliate
    ├── website.jpeg            ← Website IoT
    ├── website-porto.jpeg      ← Portfolio Website
    └── dpmd.jpeg               ← DPMD Gianyar

🔧 Langkah-langkah Setup

STEP 1: Buat Folder Utama

Buat folder baru dengan nama portfolio-andika-bramastra (atau nama lain yang Anda inginkan)

STEP 2: Copy File Utama

Copy 3 file yang sudah didownload ke folder utama:

  • index.html
  • styles.css
  • script.js

STEP 3: Buat Folder 'files'

Di dalam folder utama, buat folder baru bernama files

Letakkan file CV Anda (format PDF) ke dalam folder ini

Rename file CV menjadi: CV_Andika_Bramastra.pdf

STEP 4: Buat Folder 'images'

Di dalam folder utama, buat folder baru bernama images

Letakkan semua foto project Anda ke dalam folder ini dengan nama:

  • project iot.jpeg - Screenshot project IoT
  • recell.jpeg - Logo/gambar Recell
  • affiliate.jpeg - Screenshot TikTok Affiliate
  • website.jpeg - Screenshot website IoT
  • website-porto.jpeg - Screenshot portfolio ini
  • dpmd.jpeg - Screenshot website DPMD
⚠️ PENTING:
  • Nama file HARUS SAMA PERSIS (case-sensitive)
  • Perhatikan spasi dalam nama file (misal: "project iot.jpeg" ada spasi)
  • Format gambar: .jpeg atau .jpg
  • File CV HARUS format PDF

📝 Cara Mengganti Nama File CV (Opsional)

Jika ingin menggunakan nama file CV yang berbeda:

1. Buka file index.html dengan text editor

2. Cari dan ganti di 2 tempat:


href="files/CV_Andika_Bramastra.pdf"
download="CV_Andika_Bramastra.pdf"


href="files/CV_Anda.pdf"
download="CV_Anda.pdf"

🌐 Cara Membuka Portfolio

Testing Lokal:

  • Double-click file index.html
  • Portfolio akan terbuka di browser
  • Test semua tombol dan link
  • Test tombol "Download CV"

Upload ke Hosting:

Untuk publish online, upload semua file dan folder ke hosting seperti:

  • GitHub Pages (Gratis)
  • Netlify (Gratis)
  • Vercel (Gratis)
  • Hosting berbayar lainnya

✅ Checklist Final

Pastikan semua ini sudah OK sebelum publish:

  • ☑️ Semua file ada di folder yang benar
  • ☑️ Nama file sesuai (case-sensitive)
  • ☑️ File CV format PDF dan bisa dibuka
  • ☑️ Semua gambar muncul di website
  • ☑️ Tombol Download CV berfungsi
  • ☑️ Responsive di mobile
  • ☑️ Semua link berfungsi
